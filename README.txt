# 1. Descripción del Proyecto
CuentaClara es un sistema de gestión financiera diseñado específicamente y segura para la administración de ingresos, egresos, presupuestos y saldos compartidos. 

Desarrollado en C# bajo tecnología de escritorio nativa, el sistema garantiza la integridad de la información mediante validaciones y opera de manera estrictamente local, asegurando la privacidad total de los datos financieros sin requerir conexión a internet.

# 2. Requisitos del Sistema
Para el correcto funcionamiento de CuentaClara, la computadora anfitriona debe cumplir con los siguientes requisitos mínimos:

- Sistema Operativo: Microsoft Windows 10 o Windows 11 (64 bits).
- Entorno de ejecución: Microsoft .NET Runtime 8.0 o superior.
- Motor de Base de Datos: Microsoft SQL Server (2017 o superior).
- Memoria RAM: 4 GB mínimo disponible.
- Espacio en Disco: 200 MB para binarios y crecimiento de la base de datos.

# 3. Instrucciones de Instalación y Ejecución Rápida CuentaClara cuenta con un proceso de despliegue automatizado:

1. Ejecute el instalador "CuentaClara_Setup.exe" y siga los pasos del asistente.
2. Inicie la aplicación desde el acceso directo generado.
3. En su primer inicio, el sistema detectará el entorno y autoconfigurará 
   la base de datos local automáticamente (ejecutando los scripts internos).
4. Ingrese con sus credenciales en la pantalla de inicio de sesión.

* Nota: Para conocer el detalle paso a paso sobre el uso de cada módulo financiero o configuraciones avanzadas, por favor consulte el documento "Manual_de_Usuario_e_Instalacion.pdf" adjunto.
